## 1. 软件是什么

「电子元件管家」是一个**完全离线可用**的元件库存管理 App：

- 管理你的电阻、电容、IC 等元件：入库、库存数量、存放位置、品牌、C 号（立创料号）
- 扫立创元件袋上的二维码快速入库
- 导入 BOM 表比对库存，一眼看出缺什么，还能**一键扣减库存**
- 导入立创购物车导出表批量入库
- 电脑和手机之间**局域网同步**，两边库存保持一致
- 可选接入 AI 接口：自动分类、规范命名、缺料替代推荐（不配置 AI 也完全不影响其他功能）

数据保存在设备本机，不需要注册账号，不需要联网。

## 2. 安装与升级

### 2.1 Windows 电脑版 🖥

1. 把发布包里的 **`Windows-x64` 整个文件夹**复制到任意位置（例如 `D:\电子元件管家`）。
   ⚠️ 不能只拷 exe——同目录的 `data\`、`flutter_windows.dll`、`dartjni.dll`、`sqlite3.dll` 必须放在一起。
2. 双击 **`电子元件管家.exe`** 运行。
3. 若双击无反应：多半是杀毒软件拦截了 `dartjni.dll` / `sqlite3.dll`，把整个文件夹加入白名单后重试。

**升级**：退出旧版 → 用新版文件夹整体覆盖 → 数据不受影响（库存和设置存在系统
`%APPDATA%` 下，与程序目录无关）。

### 2.2 Android 手机版 📱

1. 把 `电子元件管家-vX.Y.Z.apk` 传到手机（微信文件传输助手、数据线、网盘均可），点击安装。
   提示「未知来源/外部来源应用」时允许即可（自签名应用，属正常现象）。
2. **覆盖升级**：v1.0.0 之后的版本共用同一签名，安装时选「更新」，**数据完整保留**；
   数据库会自动完成版本升级（如 v1.1.1 新增的「品牌」列是安装后首次启动自动补的，无感知）。
3. 更早的 `com.example` 测试版与正式版是两个不同应用，需先卸载测试版（其数据无法带走）。
4. 首次扫码时会申请**相机权限**，允许即可；拒绝后可在系统设置中补开。

## 4. 添加与编辑元件

点 **「+ 添加元件」**（或在列表长按某个元件 → 编辑）打开表单：

| 字段 | 说明 |
|---|---|
| **型号 \*** | 必填。输入后会自动按型号猜分类（改过分类下拉后不再打扰） |
| **CID（立创编号，可空）** | 形如 `C` + 至少 5 位数字。**留空 = 无 C 号散料**，系统自动生成隐藏内部编号入库，界面上不会出现这串编号。输入已有 C 号时会实时提示「已存在 / 已在回收站 / 可用」 |
| **分类** | 系统 29 类 + 你的自创分类 |
| **品牌** ⚡ | 可选。如 `国巨`、`三星`、`TI`。同型号不同品牌各自存一行，列表自动聚合显示总量 |
| **封装 / 位置 / 备注** | 均可选。位置如 `A1-3 抽屉` |
| **数量** | 滑块（1~1000）与数字框双路联动，超过 1000 直接在数字框输入 |

表单里的三个智能按钮（型号或 CID 非空时出现）：

- **从立创查料自动填充** 🖥📱（需合法 C 号）：查立创国际站，自动填型号/分类/封装/品牌/备注。查不到只提示，不动你已填的内容。
- **AI 命名** ⚡：把长描述规范成厂商标准型号（例：`贴片电阻 10K 1% 0805` → `RC0603FR-0710KL`），顺带补品牌。走 AI 1。
- **AI 查询**：AI 判断分类 + 封装/备注空槽回填；已存在的重复 C 号保存时会问你要不要「增加数量」。

保存成功会有轻震动反馈 📱。

> **C 号重复怎么办？** 同一 C 号可以有多行（不同位置）。但通过「添加」保存撞号时，
> 弹窗会让你选择：**增加数量**（合并进已有行）或取消。

## 5. 扫码入库

点主列表顶栏的扫码图标进入。

### 📱 手机：相机直扫

对准立创元件袋上的二维码即可。识别后自动弹出确认框：

- **新型号** → 「确认入库」框：型号可改，数量从二维码预填（如 250），分类自动识别——
  本地规则判成「其他」时会自动发起一次 AI 分类（没配 AI 就保持「其他」，不打扰），
  也可随时点「AI 查询分类」/「AI 命名」⚡/填品牌 ⚡；
- **已存在的 C 号** → 弹出「该元件已存在，当前数量 X」→ 确认**增加数量**（默认预填扫码数量，可±调整）；
- **回收站里的 C 号** → 确认后**恢复并加量**，不用手动去回收站捞。

扫完页面保留，可以对着整筐料袋**连续扫**；左上角 ✕ 退出返回列表。

### 🖥 电脑：无摄像头降级

电脑版没有扫码取景框，提供两个入口：

- **从剪贴板粘贴二维码内容**：在立创 App/网页上复制元件二维码文本（形如
  `{on:SO26081518766,pc:C2977076,pm:XL-1608UPC-06,qty:250,...}`），点粘贴即可，
  解析逻辑与手机完全一致；
- **手动输入 CID / 型号**：直接打开添加表单。

> 解析器兼容：立创花括号格式、`pc=/pm=` 参数、`szlcsc.com/xxxx.html` 链接、
> 裸 `C+数字`、纯文本兜底当型号——扫到杂码不会崩，最多让你手动补。

## 6. 元件列表：双列布局、搜索、排序、回收站

### 6.1 双列分类分区 ⚡

「全部元件」页默认排序（创建时间 新→旧）下：

- 列表按**分类分区**：每个分类一个标题（分类名 + N 组），下面是**双列瓦片**，
  分类顺序 = 系统 29 类 + 自创分类；空分类不显示；
- 顶部汇总：`共 N 个元件 · M 组（同型号已聚合）`；
- 每个瓦片显示：分类首字圆形图标、型号、**合计数量角标**、分类、以及 C 号/品牌/位置摘要；
- 数量 ≤ 0 的瓦片自动变灰并标「缺货」。

切换到「缺货优先（数量升序）」或「数量降序」时，取消分区，改为**全库双列平铺**，
按**组的总数量**排序——快速找到该补的料。

### 6.2 搜索

顶部搜索框按**型号 / CID** 模糊搜索（带拼写容错：差一两个字母也能找到），
250ms 防抖即输即搜；点右侧 ✕ 清空。搜索结果同样以双列聚合瓦片呈现 ⚡。

### 6.3 点击与长按

- **点瓦片**：单条 → 直接进详情页；聚合组 → 进组明细页（见下节）；
- **长按瓦片**：弹操作菜单——编辑 / 复制 CID / 删除（软删）/ 详情；
- 下拉列表可**手动刷新**。

### 6.4 回收站

点顶栏垃圾桶图标进入回收站视图（单列原始行）：

- 删除元件是**软删除**：进回收站、不丢数据、可通过局域网同步传播；
- 在回收站里可以：**恢复**单个元件，或进详情**彻底删除**（不可恢复）；
- **被 BOM 引用过的元件不允许彻底删除**，会提示先从 BOM 中移除；
- 回收站视图也支持搜索。

## 7. 品牌与同型号聚合 ⚡

这是 v1.1.1 的核心改动之一，回答「一个型号进了好几个牌子怎么管」：

- **入库时**：在添加/扫码表单填「品牌」（立创查料、AI 命名、购物车导入都会自动填）；
- **外面（首页/搜索）**：同型号（不区分大小写、忽略首尾空格）自动**聚合成一个瓦片**，
  数量角标显示**所有品牌之和**，副标题标注 `N 条 · M 个品牌`；
- **点进去（组明细页）**：逐行列出每个品牌/批次的**单独数量**、C 号、位置，
  每行可单独编辑、删除、进详情；顶部卡片显示「合计」；
- 同型号但**分类不同**时不强行合并（避免语义混乱），各归各的分类区。

> 旧数据没有品牌？没问题，品牌可空。之后任何时候在「品牌」字段补填，或重新
> 导入一次购物车/立创查料即可自动填上。

## 8. 元件详情页：合并 C 号与绑定 C 号

点元件 → 详情，展示全部字段（型号/CID/分类/品牌/封装/位置/数量/创建与更新时间/备注/删除时间）。

顶栏操作：**编辑**（回收站里的行显示**恢复**）、**彻底删除**。

### 「无 C 号」散料的转正通道 ⚡

剪板料、散装料当初没 C 号入库的，详情页底部有两个入口：

1. **合并到真实 C 号**：搜索库存里已有的真实 C 号元件 → 确认后把无 C 号行的数量
   **并入**那一行，本行自动进回收站（墓碑同步到对端，两边一致消失）；
2. **绑定该 C 号**：搜不到（库里还没有这个料）且输入的是合法 C 号 → 直接把本行的
   编号「认领」为该 C 号，数量不变、还是一行。若该 C 号已被别的元件占用，会提示改用「合并」。

全程人工确认，程序不会自动改你的编号。

## 9. 分类页与自创分类

底部「分类」标签 = 分类卡片墙：29 个系统分类 + 你的自创分类，每张卡显示
分类名和当前在用件数，「自创」角标区分来源。

- **点卡片**：放大转场进入该分类的元件列表，页内可搜索、编辑、删除该分类中的元件；
- **右上角 🎛 管理分类**：
  - **新建**：名字 ≤20 字，不能与系统类或已有自创重名；
  - **改名**：在用元件会**同步改**到新分类（回收站里的墓碑行不动，不影响同步）；
  - **删除**：还有元件在用的分类**禁止删除**（会提示数量），空了才能删；
  - 系统 29 类只读，不可改名/删除（展开可查看各类件数）。

典型用法：散料细分「钽电容」「Type-C 公头」——既可以在这里建，也可以在添加/扫码
时让 AI 给出新分类后**一键创建为自创分类**。

## 10. BOM 比对库存（含扣减库存 ⚡）

主列表顶栏 上传图标 →「BOM 比对库存」。

### 10.1 流程

1. **选择 BOM 文件**：支持 `.csv` 与 `.xlsx`（立创 BOM 工具、嘉立创导出、Excel 手写的都行）；
2. **列映射**：自动识别「型号 / 数量 / 位号」列，识别错了可手动改下拉框；
   下方预览前 5 行原始数据；
3. 点 **「对比库存」**，每行给出三态：

   | 徽章 | 含义 |
   |---|---|
   | 充足（绿） | 库存 ≥ 需求 |
   | 缺 N（橙） | 有库存但不够，短 N 个 |
   | 待采购（红） | 库存里完全没有这个料 |

   匹配规则：先按 C 号精确匹配，再按型号模糊匹配（容忍 1~2 个字符的输入差异）。
   汇总卡显示：充足/缺货/待采购行数与**缺料合计**。
4. **导出报告**（TXT，逐行带状态与位号）/ **采购清单**（CSV 带 BOM 头，Excel 直接打开不乱码，只含缺料行）。

### 10.2 按结果扣减库存 ⚡

比对结果下方新增 **「按结果扣减库存」** 按钮：

- 对所有**命中库存**的行，按该行**需求量**从对应元件里扣（同一元件被多行用到会累加）；
- 待采购行（没命中的）不扣；扣完数量下限为 0，不会出负数；
- 点击后弹**二次确认**（会扣多少行、共多少个元件），确认后单事务执行，
  失败整体回滚，随后**自动重新对比**刷新三态；
- 扣减本质是一次正常库存修改，会刷新更新时间，**局域网同步时自动带到对端**；
- 扣错了？直接在元件详情/编辑里把数量改回去即可。

适用场景：开工一台板子之前点开 BOM 扣一次，库存就是真实余量。

## 11. 缺料替代：双方向 AI 推荐与电气参数对比 ⚡

这是替代方案的核心页，三种推荐来源互相补充：

### 11.1 每行的「替代」按钮

对比结果里所有**非充足行**右侧都有「替代」按钮（跑过批量后还会显示 `AI×n` 徽标）。
点开替代面板，自上而下三块：

1. **本地库存替代（离线粗筛）**：纯本机计算（同分类/型号相近/封装相符打分），
   不联网、不要 AI 配置，点型号即复制；
2. **AI 库存替代** ⚡（按钮）：把你的**整份库存清单**发给 AI，让它从**你已有的料**里
   挑真正参数兼容的替代（比字符串粗筛准得多），并给出电气参数对照；
3. **AI 网络替代** ⚡（按钮）：AI 推荐**市面可采购**的替代型号，带参数与结论。

两个 AI 方向**各自独立**：一个失败不影响另一个，单独报错、可单独重试，
超时自动中止（默认 90 秒），**不会无限转圈**。

### 11.2 电气参数对比页 ⚡

AI 候选右侧的 **对比图标**（或批量页里的「对比」按钮）打开**两列对比表**：

| 参数 | 原元件 | 候选 |
|---|---|---|
| 阻值 | 10kΩ | 10kΩ ✓ |
| 精度 | ±1% | ±5% ⚠ |
| 封装 | 0805 | 0805 ✓ |

- 逐项标注 ✓ 一致 / ⚠ 不同 / — 缺失，一眼看出关键差异；
- 顶部有替代结论徽章：**可直接替代 / 需确认 / 不建议**，附一句关键差异说明；
- 多个候选时顶部可切换对比对象。

### 11.3 一键批量：AI 缺料替代处理页 ⚡

对比完成后，下方出现 **「AI 一键推荐缺料替代（N 项）」**，进入全屏处理页：

- **元件一个一个找**：每个缺料元件单独请求一次 AI，**出一个建议立刻挂出一个**，
  顶部显示「第 i/N 个：型号…」+ 进度条 + ✓/✗ 计数；
- **双方向开关**：顶部「库存替代 / 网络替代」两个 FilterChip，默认全开；
  中途关一个只影响后续行；每行结果按方向分组展示（`网络替代 ×2`、`库存替代 ×1`）；
- 单行失败标红并给原因（可**单独重试**），不影响后面的元件；
- 随时点 **⏹ 停止**：已出的建议全部保留，剩余行不再请求；
- 返回 BOM 对比页后建议**缓存在页内**（`AI×n` 徽标），点该行「替代」直接带出，
  不重复花请求；改列映射/换文件才作废。

> 建议先跑一次批量，再逐行点「替代 → 对比」做人工确认——AI 负责找，你负责拍板。

## 12. 立创购物车批量入库（含 AI 命名 ⚡）

适合刚下完单一车料要全部建档的场景。

1. 立创商城 App/网页 → 购物车 → 导出（CSV 或 Excel），列如：
   `购买类型 / 商品编号 / 商品分类 / 名称 / 商品型号 / 品牌 / 封装规格 / … / 购买数量 / 单价`；
2. 主列表 上传图标 → **「立创购物车入库」** → 选择文件；
3. 列映射自动识别（编号/型号/数量/分类，品牌、封装也认），可手动调整；
4. 确认卡片显示「有效 N 行待入库（同 C 号已合并数量）」，无效行会列**跳过原因**；
5. ⚡ **「AI 自动规范命名」开关**：打开后入库前把**整表名称一次 AI 调用**规范成
   厂商标准型号并补品牌（名称乱七八糟的导出表特别有用）；
   AI 挂了会自动按原名入库，绝不阻塞；
6. 点「导入库存」。入库规则以 **C 号为唯一键**：
   - 库里没有 → 整行新增（型号/分类/封装/品牌/备注齐全）；
   - 已有 → **只累加数量**，你手工维护过的型号、分类、位置一概不动；
   - 在回收站 → 自动恢复 + 累加；
7. 结果报告：新增 X · 累加 Y · 恢复 Z · 跳过 N，并列出跳过原因。

## 13. AI 功能配置（AI 1 / AI 2 双接口）

**设置页 → AI 查询** 卡片，两组配置：

| | AI 1（基础） | AI 2（增强）⚡ |
|---|---|---|
| 负责 | 元件分类、AI 命名 | **元件替换推荐**（库存替代 + 网络替代） |
| 是否必填 | 用 AI 功能才需要 | **可留空**，留空时替换功能自动回退用 AI 1 |
| 建议 | 便宜快的小模型即可（deepseek-chat、gpt-4o-mini、本地 Ollama） | 建议推理更强的（deepseek-reasoner、gpt-4 级别），替换推荐质量差主要吃模型 |

每组三个字段：**Base URL**（如 `https://api.deepseek.com/v1`）、**API Key**
（本地 Ollama 等无密钥服务可留空）、**模型名**。填完分别点「测试连接」/「测试 AI 2」验证。

- 支持任何 **OpenAI 兼容** 接口；内网服务需显式写 `http://` 前缀；
- Key 明文存在本机数据库里（与同步令牌同级），只在调用时发给接口，
  **不随局域网同步传播**；不点 AI 按钮就绝不会外发任何数据；
- 单次请求最长 **90 秒**超时自动中止并提示，不会出现"永远转圈"；
- 分类结果不满意：AI 给的新分类（不在你现有清单里的）会弹窗问你是否
  **创建为自创分类并采用**，取消则按型号规则兜底，不污染分类表。

不用 AI 能干活吗？能。扫码分类兜底是本地规则引擎，BOM 比对、购物车入库、
同步、备份全部离线可用；AI 只是锦上添花。

## 14. 局域网同步（电脑 ⟷ 手机）

让家里的电脑和手机持有同一份库存。两台设备连**同一个 Wi-Fi/路由**。

### 14.1 一次性准备 🖥

电脑首次开主机时，Windows 防火墙弹窗请**允许**（需要 TCP 8321 与 UDP 8322 入站）。
没弹窗或被拦过：控制面板 → 防火墙 → 高级设置 → 入站规则手动放行这两个端口。

### 14.2 主机端（通常选电脑）

1. 主列表 → 同步图标 → 进「局域网同步」页；
2. 「主机模式」卡片：确认端口（默认 8321，可改），点 **开启主机**；
3. 页面显示本机 IP、发现名称、已同步次数与进度条；
4. **开启期间不要退出这个页面**（服务随页面关闭而停止）。

### 14.3 客户端（通常选手机）

两种方式，推荐第一种：

- **自动发现主机**：点「自动发现主机」→ 约 2 秒列出局域网内的主机 →
  **点一下就直接完成同步**（IP/端口/令牌自动回填，下次进页面还会记住上次的主机）；
- **手动输入**：填主机 IP（页面上抄）+ 相同令牌 → 开始同步。

### 14.4 同步里发生了什么

- **双向全量合并**：不是覆盖！两台设备各自的修改都会保留，按「更新时间新者胜」；
- 软删除作为**墓碑**传播——这边删了，同步后那边也消失；
- BOM 单据与明细一并同步（单据按「名称+创建时间」去重）；
- 5 分钟内两边改过**同一条**且改得不一样 → 判为**冲突**，客户端逐条裁决：
  **保留本地 / 保留远端 / 保留两者（数量相加）**；
- 同步令牌是弱校验 + 数据 Base64 明文传输，**请只在可信局域网（家里/工作室）使用**；
- 两台设备**系统时间请保持基本一致**，时钟差太大会造成新旧误判；
- 部分路由器/手机热点开了「AP 隔离」会拦广播导致发现不到——改用手动输入 IP 即可。

> 建议节奏：在电脑干完活 → 手机上点一下自动发现的主机 → 完成。冲突很少出现，
> 出现了面板里三条按钮点一下就行。

## 15. 备份与恢复

设置页 →「数据备份与恢复」：

- **导出备份**：全量数据（含回收站元件、BOM 单据与明细）存成一个 JSON 文件。
  🖥 弹系统另存为对话框挑位置；📱 存到应用临时目录并提示路径（可再微信转发存档）。
  建议：大动作（批量导入、同步前、换机前）先导一份；
- **恢复备份**：选 JSON → 确认 → **清空并覆盖**当前全部元件与 BOM（不可撤销，
  恢复前请先导出当前数据）。备份格式版本不兼容会直接拒绝、不动当前库；
- 备份**不包含** AI Key、同步令牌、设备 ID（换机重配即可，属安全考虑）。

换机迁移：旧机导出备份 → 新机恢复 → 或者干脆两台开同步互拉一次。

## 17. 常见问题 FAQ

**Q：电脑版双击没反应？**
杀软隔离了 `sqlite3.dll`/`dartjni.dll`，加白名单后重新解压一份完整目录。

**Q：手机装不上 / 提示签名冲突？**
装过 `com.example.*` 的早期测试版会导致签名冲突，先卸载那个「Example 版」再装正式版。

**Q：为什么我删掉的元件同步后又"复活"了？**
对端在删除之后又编辑过同一条（更新时间更晚），LWW 判定编辑获胜。去对端再删一次。

**Q：自动发现找不到主机？**
① 对方主机页没开着；② 不在同一网段；③ 路由器开了 AP 隔离/访客网络。用手动 IP。

**Q：AI 按钮点了没反应/报错？**
看提示文案：未配置 → 去设置页；401/403 → Key 错了；超时 → 接口太慢，稍后重试
（网络替代方向尤其吃模型速度，可把 AI 2 配成更快的模型）。

**Q：同型号元件为什么首页只有一条？**
这是 v1.1.1 的聚合显示（数量=合计），点进去看各品牌单独的量和批次。

**Q：BOM 比对匹配错了？**
模糊匹配容忍 1~2 字符差异，极端情况会认错。用「导出采购清单」时核对一下，
或直接给元件补上 C 号（精确匹配优先）。

**Q：扣减库存扣多了？**
扣减等同一次普通编辑：进元件详情改数量回去即可，然后同步。

**Q：数据到底存在哪？**
🖥 `%APPDATA%\<组织>\component_manager\component_manager.db`；📱 应用私有目录。
卸载 App（手机）会带走数据——**卸载前务必导出备份**。

**Q：能不能多人用同一份库存？**
同步协议是双人 LWW 合并，理论上可轮流同步，但没有权限控制，建议当作
「个人多设备」工具使用。
